Scanner Detection

Tune how the per-campaign “Ignore security scanner interactions” option decides that an open/click came from a mail security scanner or sandbox (e.g. Microsoft Defender Safe Links) rather than a real recipient. An interaction is treated as a scanner when it happens within the time window after sending and its User-Agent matches a risky string or an outdated browser version.

Interactions later than this after the email was sent are never treated as scanners.
A browser whose major version is below the minimum for its engine is treated as outdated (a sandbox tell — Safe Links pins an old Chrome). Set 0 to disable the version check for that engine.
Case-insensitive substring match against the interaction's User-Agent.
